DEVELOPER API

Drive Wave Cinema programmatically — projects, plans, generation, billing. Same engine as the web UI.

Authentication

Create a token on your Account page. Tokens look like wc_<32 hex chars> and are shown once. Send it as a header on every request:

Authorization: Bearer wc_9f2c…

Rate limit: 60 requests/minute per token. Tokens are scoped to your account — you can only see your own projects and billing.

REST endpoints

Base URL: https://wave-cinema.onrender.com

MethodPathWhat it does
GET/api/v1/capabilitiesEndpoints, aspects, resolutions, lanes
GET/api/v1/projectsList your projects
POST/api/v1/projectsCreate a project — body: {"name": "My film"}
GET/api/v1/projects/{pid}Project snapshot (cast, stage, plan status)
POST/api/v1/projects/{pid}/directRun the director — body: {"treatment": "…"}
GET/api/v1/projects/{pid}/planShot plan with per-scene prompts
POST/api/v1/projects/{pid}/generateQuote + approve + generate one scene — body: {"scene_id": "s0"}
GET/api/v1/projects/{pid}/takesTake history (optional ?scene_id=)
GET/api/v1/billing/balanceYour credit balance
GET/api/v1/billing/ledgerUsage history (optional ?limit=)

Errors are JSON {"error": "…"} with proper status codes: 401 bad token, 402 payment needed, 403 wrong owner, 404 missing, 429 rate-limited.

Example

TOKEN=wc_your_token_here
BASE=https://wave-cinema.onrender.com

# list projects
curl -s -H "Authorization: Bearer $TOKEN" $BASE/api/v1/projects

# create one
curl -s -X POST -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"Midnight Drive"}' $BASE/api/v1/projects

# check balance
curl -s -H "Authorization: Bearer $TOKEN" $BASE/api/v1/billing/balance

MCP server (for AI agents)

An MCP server lives at /mcp (streamable HTTP, JSON-RPC 2.0). Same bearer auth. Tools:

list_projects · create_project · get_plan · generate_scene · get_balance · get_ledger

# initialize
curl -s -X POST $BASE/mcp \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize",
       "params":{"protocolVersion":"2024-11-05",
                 "capabilities":{},"clientInfo":{"name":"cli","version":"1"}}}'

# list tools
curl -s -X POST $BASE/mcp \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/list","params":{}}'

Point any MCP-compatible agent (Claude Code, Codex, OpenClaw, …) at $BASE/mcp with your token.
